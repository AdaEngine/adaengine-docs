Terrain

Create editable ground with Terrain3D. Its heights describe one square surface in the entity’s local X/Z plane. Model3DPlugin generates the visible geometry; Physics3DPlugin adds matching static triangle collision.

Mesh Terrain uses a Terrain3DSource whose .aterrain manifest references an .atmesh document. Keep the manifest, its document, and its relative resources together. The document retains the source sections and ordered modifiers. Its compiled product contains the triangles and placement records that the runtime can use without the desktop authoring kernel.
