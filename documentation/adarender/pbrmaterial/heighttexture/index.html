heightTexture

Height map for parallax occlusion mapping, read from the red channel (1 is the top of the surface, 0 the deepest point). Use a linear (non-sRGB) texture. Parallax shifts every material texture that shares , so the relief stays consistent with color, normal and occlusion maps. The shader has no free sampler slot, so the height map is read with the base color texture’s sampler: give both the same address and filter modes.
