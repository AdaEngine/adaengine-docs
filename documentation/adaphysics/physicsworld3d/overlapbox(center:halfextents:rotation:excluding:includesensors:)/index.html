overlapBox(center:halfExtents:rotation:excluding:includeSensors:)

Tests the complete oriented box against native shapes, rather than only its AABB. Call between physics steps on the serialized world. Sensors are ignored by default. Returns nil for invalid input; nil must never be interpreted as a clear volume. A finite, safely normalizable quaternion is normalized. Touching follows Box3D’s overlap tolerance. The reported entity belongs to the first accepted shape; traversal order is unspecified.

@MainActor func overlapBox(center: Vector3, halfExtents: Vector3, rotation: Quat = .identity, excluding entity: Entity.ID? = nil, includeSensors: Bool = false) -> OverlapBox3DResult?
