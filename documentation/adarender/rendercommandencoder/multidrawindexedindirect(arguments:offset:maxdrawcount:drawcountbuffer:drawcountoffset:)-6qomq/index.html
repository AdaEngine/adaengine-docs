multiDrawIndexedIndirect(arguments:offset:maxDrawCount:drawCountBuffer:drawCountOffset:)

Encodes up to maxDrawCount consecutive GPU-generated indexed draws; the GPU reads the actual number, a UInt32, from drawCountBuffer at drawCountOffset. Returns false without encoding when unsupported.

func multiDrawIndexedIndirect(arguments _: any Buffer, offset _: Int, maxDrawCount _: Int, drawCountBuffer _: any Buffer, drawCountOffset _: Int) -> Bool
