Animate a 3D character from movement

Use CharacterLocomotion3DComponent to play skeletal animations from an upright 3D character’s actual movement. Add it to the root entity that owns the character controller and skinned model. Your input or AI continues to set desiredVelocity and jumpRequested. Locomotion reads the resolved motion after physics, so holding forward against a wall can leave the character idle.

Enable the 3D model and physics plugins in your game. Add a static floor and put your skinned model in the project assets. This example uses Character.glb and the default clip names. Spawn the character’s root entity in the scene world.

The default component maps Idle, Walk, Run, Jump, Fall, and Land. After the character accelerates it walks, then runs at the higher speed. Releasing movement returns it to idle after braking. Jump plays on ascent, Fall holds its final pose during descent, and Land plays briefly before the character resumes the current grounded gait. Stepping off a ledge goes straight to Fall after two consecutive ungrounded physics samples.
