RenderPipelining

Opts a subworld, normally a render world, into pipelined updates.

A pipelined subworld runs one frame behind its parent. The parent extracts frame N into it, starts its update and continues with frame N+1 without waiting. Before the next extraction the parent waits for that update to finish, so extraction remains the only point where both worlds meet. Frame time approaches the longer of the two paths instead of their sum, at the cost of one frame of input latency.

While a pipelined update is in flight, systems of the subworld must not read the parent world (see Extract and MainWorld), and parent systems must not mutate objects the subworld reads. Set ADAENGINE_PIPELINED_RENDERING=0|1 to override the setting of every world that declares this resource, for measurements. Pipelining is unavailable on WebAssembly, where the setting is ignored.
