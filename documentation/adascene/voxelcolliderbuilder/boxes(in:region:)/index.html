boxes(in:region:)

Greedily merges solid cells of region (the whole grid by default) into boxes.

Cells are merged along X first, then Y, then Z. Box origins are relative to the region’s minimum corner. Every solid cell belongs to exactly one box, so the union of the boxes equals the solid volume.

static func boxes(in grid: VoxelGrid, region: VoxelMeshingRegion? = nil) -> [VoxelBox]
