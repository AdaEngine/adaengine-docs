createBundled(at:from:defines:)

Compile a bundled shader with every name in defines set to 1 in the vertex and fragment stages.

The variant is compiled from the file’s text rather than the file, so it bypasses the on-disk shader cache, whose entries are keyed by file and stage and would mix up variants of one file. Callers should keep the result. WebAssembly builds ship precompiled modules, so there the plain module is returned and defines are ignored.

static func createBundled(at path: String, from bundle: Bundle, defines: [String]) throws -> ShaderModule
