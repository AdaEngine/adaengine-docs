MorphWeights3DComponent

The weights of an entity’s morph targets (blend shapes), one per target of its mesh.

A weight of 1 applies a target’s full displacement and 0 none; values outside that range extrapolate. The renderer applies at most eight targets at once, the ones with the largest weights, and moves vertices before skinning. A model instantiated from glTF gets this component with the weights the file defines.

Scripts and the inspector cannot read arrays, so they steer one target at a time: pick it with or and set . Code can use and directly.
