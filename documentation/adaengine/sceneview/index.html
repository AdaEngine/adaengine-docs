SceneView

A view that creates a separate offscreen runtime with its own World, renders it into a RenderTexture, and embeds the result into the AdaUI view hierarchy.

The make closure is called exactly once per SceneView instance before the runtime is built. Use it to configure plugins, resources, and initial scene content. Set useSceneCameras to render with the game’s active cameras (including 3D) instead of creating a default 2D viewport camera. Their projections and transforms are preserved; render targets and viewport sizes are owned by this view. onFrameRendered receives the scene texture on the main actor at the next UI update after GPU completion, when the frame becomes visible to the view. Read pixels during the callback; the texture is reused for subsequent frames. Set updatesWhenWindowInactive to false for editor previews: their runtime and rendering stop while the containing window is inactive, retaining its last texture.
